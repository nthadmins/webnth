# NTH Digital Market

Trang web tĩnh bằng HTML, CSS và JavaScript, chuẩn bị cho GitHub Pages.

## Chạy thử

Mở file index.html trong trình duyệt.

## Đưa lên GitHub Pages

1. Tạo một repository công khai trên GitHub.
2. Đưa index.html vào thư mục gốc của repository.
3. Mở Settings → Pages.
4. Chọn Deploy from a branch, nhánh main và thư mục / (root), rồi lưu.

GitHub Pages miễn phí yêu cầu repository công khai trên gói GitHub Free. Địa chỉ trang dự án sẽ có dạng https://<tên-tài-khoản>.github.io/<tên-repository>/.

## Trước khi mở bán

- Thay sản phẩm, giá, số lượng và nội dung minh họa bằng thông tin thật.
- Thay thông báo, phản hồi mẫu và nút hỗ trợ bằng thông tin của cửa hàng.
- Giao diện đăng nhập, số dư, đơn hàng và thanh toán hiện chỉ là bản demo. Cần backend riêng để xử lý tài khoản, đơn hàng và giao dịch thật.
